CÓMO EDITAR MÁS ADELANTE
1. Abre catalogo.js en GitHub y pulsa el lápiz (Edit).
2. Cada producto tiene: name (nombre), cat (categoría), size (tamaño/presentación), price (precio en pesos colombianos, solo número) e img (URL de la fotografía).
3. Para agregar un producto, duplica una línea completa, cambia sus datos y conserva la coma al final. La última línea puede llevar coma también.
4. Pulsa Commit changes para guardar. GitHub Pages publicará los cambios automáticamente en unos minutos.
5. Para cambiar fotos, sube tus imágenes a la carpeta assets y coloca una ruta como 'assets/monstera.jpg' en el campo img.

CÓMO PUBLICAR EN UN REPOSITORIO NUEVO
1. En GitHub, crea un repositorio público nuevo, por ejemplo huella-verde-jardineria.
2. En Add file > Upload files, arrastra index.html, catalogo.js y la carpeta assets completa.
3. Pulsa Commit changes.
4. En Settings > Pages, en Build and deployment selecciona Deploy from a branch.
5. Selecciona la rama main y la carpeta /(root), y pulsa Save.
6. Espera unos minutos. GitHub mostrará la dirección pública del sitio en Settings > Pages.
